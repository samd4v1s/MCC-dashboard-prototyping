# MCC-dashboard-prototyping
For building mockup dashboard templates with dummy data.

## Run the dashboard

From this repository's root directory, start a local web server:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/index.html`. The page fetches `app.py`, so it must be served over HTTP from the same directory rather than opened directly as a file.
